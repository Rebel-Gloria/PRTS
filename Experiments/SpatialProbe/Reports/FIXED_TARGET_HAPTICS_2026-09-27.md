# 固定最远目标与左右节奏触觉（build 10）

日期：2026-09-27（Asia/Shanghai）。本次更改已经完成编写、核心验证和unsigned iOS编译；**未安装到真机**，签名描述文件过期且Xcode没有可用账号。没有修改旧项目、系统配置或购买服务。

## 目标选择与保持

- 新目标在相机地面前向扇形内选择，默认左右各45°（可调15–75°），距离受当前观测和默认4m径向上限限制。
- 在满足0.50m总宽度及既有地面/障碍支持要求的可达格中，最大化目标到相机地面投影的平面欧氏距离。不再比较与正前方的角差，也不以绕路长度代替目标距离。等距仅以路线代价和固定索引破同分。
- 目标世界坐标、ID固定；后来看到更远蓝面不移动目标。允许裁短已走部分和重新绕障，但终点保持同一个精确世界点，不随当前栅格中心漂移。
- 到达阈值默认0.35m（相机地面投影，不是真实双脚）。超范围判定带5°/0.2m余量、0.3s退出滞回；确认后解除目标再寻找下一个。
- 目标意图和几何证据分开：缺数据时先保留有时限的历史线，过期隐藏并停振；目标元数据保留，恢复后尝试连接同一点。
- 路径新遇障碍而暂不能绕行：清除原连线/提示，**保留目标**等待重建，不为增加画线率随意换点。目标足迹本身确实被当前障碍占据，或地面/尺度/AR追踪与会话代次失效时，才按安全例外解除目标。
- 原严格候选栅格、未知区和身体净空判定不变；青虚线仍是未验证的近身连接。

## 振动状态机

| 状态 | 默认规则 |
|---|---|
| 连线偏左，尚未对准 | 重复双短振，每段60–80ms、组内间隔90ms |
| 连线偏右，尚未对准 | 重复单长振，180–260ms |
| 偏差增大 | 强度约0.30→0.80，重复周期约0.85→0.45s；一组模式不会跨到下一组 |
| 进入正确角度 | ±5°内连续0.3s，取消方向模式并强振一次（强度1、180ms） |
| 已确认 | 保持静默，小幅偏移、同目标重验证/重规划和短暂缺帧不重复强振 |
| 再次明显偏离 | 达到12°并连续0.25s，恢复方向节奏；再次对准才重新允许强振 |
| 换侧/无效/暂停 | 换侧取消旧模式；失效、后台、设置、禁用等立即停止，不补播 |

- 对准只判断连线角度，不声称横向位置正确、人在路径中央或路径安全。单个振动器靠节奏区分左右，不是两个方向的物理振动器。
- 正常AR追踪的转向中使用最新位姿做角度反馈，不因单独的选点角速度稳定门限停振；选新目标仍需稳定。追踪异常、姿态前向不可投影、证据过期等仍停振。
- 超过250ms的反馈缺口不能算作持续对准/偏离证据。API提交失败不进入“已确认”锁定，退避后可重新确认；实际人体感受到的触感仍须真机测试。
- CoreHaptics每次只播放一组短模式，无无限排队任务；没有音频、麦克风或新权限。

## 真机待验收

先由视力正常人员在受控环境原地测试，勿边走边首次辨认模式：
1. 目标出现后缓慢/正常转动手机，确认左双短与右长振能区分，换侧没有旧模式残留。
2. 连续对准±5°约0.3s后只强振一次；在±5–11°附近反复小幅偏离/回来应保持静默；偏离≥12°稳定0.25s后才恢复，再对准才强振。
3. 目标固定期间扩大可见蓝地面、短暂遮挡地面，不应仅因有更远点/数据中断改变目标坐标；过期线仍应隐藏并停振。
4. 目标途中放入障碍，验证原线立即停止，能绕则仍到原目标；暂不能绕则保留目标等待；目标本身被占据才解除。
5. 用卷尺观察0.35m到达半径；跨角度/距离范围测试滞回，核对DIAG中的goalChangeReason。
6. 停止、后台、追踪丢失时无持续振动；继续做30分钟性能与发热测试。
