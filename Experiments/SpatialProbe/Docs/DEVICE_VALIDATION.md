# 真机验证清单（待执行）

**第一个验收里程碑始终是 M1：真机 RGB＋深度＋置信度正确对齐。** 后续实现已可编译，但不意味着跳过M1。所有行走测试由视力正常人员在受控环境完成；禁止无保护盲行；台阶只做有人防护的受控观察。

## 0. 安装与准备

- [ ] Xcode选择合法Team、独立Bundle ID；保持LiDAR iPhone连接、解锁，处理系统信任／签名提示。
- [ ] 运行后批准相机；检查world／sceneDepth／mesh classification分别为支持。
- [ ] 记录iPhone型号、iOS、App build、源码归档、环境光、时间、设备初始温度状态和参数。
- [ ] 测量测试者宽度、身高、实际持机高度，配置宽度与单侧余量；参考方向只是相机地面投影。
- [ ] 场地安全隔离、旁观协助、卷尺、箱子／椅子／桌子；确认现场影像采集许可。
- [ ] 默认RGB仅手动采样；不得在无关人员场景中连续记录。

## M1：RGB／原始深度／置信度

1. 先关闭网格／floor／栅格／通道。使用静态、不透明、有清晰边缘的箱体，测试0.5、1、2、3m。
2. 每个距离分别放在画面中央和四周，检查竖屏、左右横屏；记录RGB尺寸、depth尺寸、orientation和显示模式。
3. 依次切换RGB、热图、置信度、半透明叠加；热图应有米制色标，置信度有0/1/2图例，缺失显示灰。
4. 全画面边缘仍可见，比例不变，无镜像／裁切／软件固定偏移。黑边是正确行为，不是缺陷。
5. 冻结并手动保存同帧样本；另外用系统截图／录屏记录显示映射。**原始样本不是截图**。
6. 分开报告：软件重投影／变换误差（像素）与深度边界混合／孔洞；不要通过插值填孔掩盖边界差异。
7. 拒绝权限、停止、切后台、恢复均不得继续标“实时”；拒绝后有明确设置入口。

验收：所有模式有效、横竖屏全视野对齐通过并存证；没有真机证据时标“已实现、未验收”。

## M2：网格与分类

- [ ] 开启网格和floor层；缓慢平移、转动、俯仰后在墙角、地面和桌沿检查叠加固定偏差。
- [ ] 区分ARKit蓝色floor分类与本应用地面支持；误分类也保存，不用分类当真值。
- [ ] 停止／开始、会话中断后旧anchor消失；无分类时灰色，不默认floor。
- [ ] 对照网格callbackTime／revision／耗时。旧mesh只是结构，不能直接证明现在无人阻挡。

## M3：地面、障碍、未知

每个静态布置至少重复3次。固定相机参考位置、障碍位置、参数和采集时长，保留布置照片及卷尺记录。

|场景|布置|应重点检查|
|---|---|---|
|空走廊|固定位置，0.5–3m范围多个截面|地面参考、全高度证据、未知比率；允许无候选|
|窄通道|宽度0.6/0.8/0.9/1.0/1.2m；默认要求0.9m|边界保守性、实际可用率，不为临界宽度放松|
|纸箱／椅子|测前缘位置、侧边、椅脚|稳健距离、细结构疑似保持未知|
|桌面／悬空障碍|记录高度、宽度、下方地面可见区域|看到地面不代表头部／躯干净空|
|玻璃／反光／低纹理|人在安全侧静止观察|深度孔洞、误深度、追踪受限，任何错误候选单独失败|
|地面缺支持|地面被挡、移出视野|不能凭平面外推候选；未知保持|

真实卷尺距离采用**相机地面投影至障碍前缘的地面距离**，不能拿手持相机到目标的斜距比较。区分格中心分位统计与物体最前缘的量化误差。初始0.5–3m静态工程目标：距离MAE≤10cm，带宽MAE≤15cm；均为待验证目标。

## M4：候选段与撤销

- [ ] 近身盲区明确未知，只从已观测起点开始，不连接脚下。
- [ ] 通道遇未知／窄区截断，不跳接远处另一段，不对角穿角。
- [ ] 行人横穿／离开：横穿时当前深度否决，离开后重新取证，不因障碍过期直接恢复绿区。
- [ ] 快速转向、roll、俯仰、相机朝上／下、追踪非normal时无确定性通道；恢复稳定至少0.5s。
- [ ] 切后台、停止、重定位、中断后清空，重新启动为新epoch。
- [ ] 无新帧／分析超时超过250ms，不保留旧段。以录屏逐帧核对，非仅查看日志时间。
- [ ] 台阶附近仅受控观察：未观测地面不能补通道；本应用**没有可靠落差检测**，不能让测试者按候选段走向边缘。

## M5：持续性能、记录、导出

1. 使用Release安装，默认10Hz、stride2，持续至少30分钟；记录墙上开始／结束时刻。不要用Mac合成测试耗时预测手机热表现。
2. 按5分钟窗统计绘制／分析FPS、各阶段耗时、源结果年龄P95、丢帧／丢记录、thermal转变；目标显示≥30FPS、分析约10Hz、年龄P95≤250ms。
3. 若serious降频或critical暂停，明确报告持续时间、对未知率和可用率影响。不得剔除困难／热状态区间美化。
4. 保存失败样本和若干成功样本；停止后导出，检查原始depth字节数=width×height×4、confidence=width×height，核对sample与analysis的epoch/frameID/参数版本。
5. 独立人工真值填写模板，运行统计脚本；未知／无读数的比例一起报告，错误候选逐事件列表单独FAIL。
6. 拒绝权限、磁盘错误、导出取消／完成、快速开始停止、参数变化、后台30秒再恢复做专项测试；这些集成路径仍需设备实际验证。

## 移动建模回归（build 2；实际结果待复测）

- [ ] 同一场景先站定建立地面，随后持续缓慢平移、左右转动及轻微俯仰。追踪正常且地面在视野内时，蓝色地面、红色物品与阻挡柱应继续更新；不应只在停下后出现。
- [ ] 适度提高转向速度触发“方向变化：几何继续更新，通道及方向距离暂停”。蓝／红几何仍随当前相机投影，黄色候选线和方向距离立即撤销；回稳至少0.5秒并产生新结果后才允许恢复。
- [ ] 移动物品后用新深度确认旧红柱消失；不保留旧模型来伪装连续识别。
- [ ] 遮挡相机、追踪受限、停止、后台和冻结时不保留确定性叠加；恢复不重现失效前的通道。超过250ms的结果不显示。
- [ ] 源帧没有可靠地面／置信度、或镜头接近竖直时仍显示未知；这是保留的能力边界。
- [ ] 保存20–30秒录屏，停止后导出日志；对应 `sourceDirectionStable`、`geometryOutputEligible`、`outputEligible` 与表面面数、结果年龄，不把几何继续显示误报为路线有效。

所有移动测试由视力正常人员在受控环境执行，不进行无保护盲行。
