# 使用说明

PRTS 使用 iPhone 相机帮助你发现前方障碍，还可以描述眼前画面、回答提问、朗读文字，并播报周围的动作变化。

## 使用方式

- **开始避障**：轻点屏幕上的“开始”，或按下操作按钮启动；也可以用 Siri 或轻点背面运行“开始 PRTS”快捷指令。
- **停止避障**：按住主按钮 1 秒。如果你打开了“点按停止”，或正在使用旁白，轻点或双指双击即可停止。
- **描述画面**：避障期间，按下任一音量键或轻点屏幕上的拍照按钮，即可听取眼前画面的简短描述。
- **语音提问**：按住音量键或拍照按钮，听到提示音后说出问题，松手就会发送。
- **流式字幕**：连按三下音量键或拍照按钮开启，开启后会持续播报画面中发生的动作；运行中再按一下即可退出。此功能需开启“允许使用云端服务”、配置通义千问的 API Key 并保持联网。
- **读文字**：三指按住屏幕不动并保持手机平稳，PRTS 会自动拍照并朗读面前路标、纸张或物体上的文字。

## 按钮提示

- 若要按下操作按钮直接启动，请前往 iPhone 的“设置”>“操作按钮”，选择“快捷指令”，然后选定“开始 PRTS”。
- 如果你希望音量键照常调节音量，请在 App“设置”的“交互”部分关闭“音量键快捷操作”，改用屏幕上的拍照按钮。

## 设置选项

- **智能**：选择使用本机模型还是联网服务来描述画面、回答问题和读文字。关闭“允许使用云端服务”不会打断已经开始的操作。选择“本机”提问时，照片和问题都留在本机。流式字幕固定使用通义千问。
- **交互**：按需开启低视力模式（保留相机和智能功能，暂停深度检测和避障提示）、点按停止、音量键快捷操作、三指读文字以及无画面模式。
- **语言和语音**：开关语音播报，调整语速和播报语言。

## 重要信息

- PRTS 是辅助工具，不能代替盲杖或导盲犬。
- 精确避障需要支持激光雷达（LiDAR）的 Pro 机型，目前尚不能识别台阶和落差。
- 开始避障时会振动两下。没有听到提示，不表示前方畅通。停止后再开始，或从读文字返回避障时，请等待新的提示。
- 如果看不到地面，iPhone 不会提示畅通或让你转向。只有很近的障碍挡住整个画面时，才会提醒你“障碍很近”。
- 如果一时测不到前方，手机只能短暂使用刚探测过的区域。离开这片区域后仍测不到时，才会提醒你“暂时看不清”。
- 描述画面、提问或打开设置时，避障语音和振动会暂停。使用流式字幕时，仍可通过振动获得避障提示。读文字时，手机会暂停探测周围的障碍。
- AI 描述和回答可能出错，前进前请结合避障提示和盲杖确认安全。

你可以随时在设置的最下方重新查看这份说明。
