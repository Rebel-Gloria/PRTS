# 使用说明

PRTS 用 iPhone 的相机帮你发现前方障碍，也能描述画面、回答问题和朗读文字。

## 准备

在 iPhone 的“设置 → 操作按钮”中选择“快捷指令”，再选择“开始 PRTS”。

## 怎么用

- **开始使用**：按操作按钮，或轻点屏幕上的“开始”。
- **停止**：按住主按钮 1 秒。
- **描述画面**：避障时按一下任意音量键。
- **提问**：按住音量键，听到提示音后说话，松手发送。
- **读文字**：三根手指按住屏幕不动。

如果你希望音量键照常调节音量，请在智能设置中关闭“音量键快捷操作”，改用屏幕上的拍照按钮。

## 可以设置什么

- **点按停止**：开启后轻点主按钮即可停止，适合不便长按的用户。
- **非盲模式**：只保留描述、提问和读文字，不提供避障提示。
- **智能设置**：选择由谁描述画面和回答问题，设置拍照按键和读文字。默认在手机上离线处理，照片不会离开手机；也可以改用联网服务。
- **语音**：开关播报，调整语速和语言。
- **显示**：关闭相机画面以省电，或显示扫描网格。

## 请注意

- PRTS 是辅助工具，不能代替盲杖或导盲犬。
- 避障需要带 LiDAR 的 Pro 机型，目前不能识别台阶和落差。
- 描述、提问和读文字时，避障提示会暂停。
- 描述和回答可能出错，能否通行请以避障提示为准。

你可以随时在设置的最下方重新查看这份说明。
