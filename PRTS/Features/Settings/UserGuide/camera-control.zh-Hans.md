# 使用说明

PRTS 通过 iPhone 相机帮你发现前方障碍，也能为你描述画面、回答提问、朗读面前的文字，或持续播报眼前的变化。

## 怎么用

- **开始避障**：轻点屏幕上的“开始”，或按下操作按钮启动；也可以用 Siri 或轻点背面运行“开始 PRTS”快捷指令。
- **停止避障**：按住主按钮 1 秒即可停止。如果你开启了“点按停止”或正在使用旁白，点按或双指双击就能停止。
- **描述画面**：避障时轻按一下相机控制按钮，就能听取眼前画面的简短描述。
- **语音提问**：按住相机控制按钮，听到提示音后说出问题，松手就会发送。
- **流式字幕**：连按三下相机控制按钮开启，开启后会持续播报画面中发生的动作；运行中再按一下即可退出。这项功能需要配置通义千问的 API Key 并保持联网。
- **读文字**：三根手指按住屏幕不动，保持手机稳定，App 会自动拍照并朗读面前牌子、纸张或物体上的字。

## 快捷按键小贴士

如果你想按下实体键直接启动避障，可以在 iPhone 的“设置 → 操作按钮”里选择“快捷指令”，再绑定“开始 PRTS”。

## 可以调整哪些设置

- **智能**：选择本机模型或联网服务来完成描述、提问和读文字。默认所有处理都在本机完成，照片不会上传；流式字幕固定使用通义千问。
- **交互**：按需开启低视力模式（只保留相机和智能问答，暂停避障提示）、点按停止、三指读文字，以及省电的无画面模式。
- **语言和语音**：开关避障播报，或调整播报语速和语言。

## 安全与使用提醒

- PRTS 是辅助工具，不能代替盲杖或导盲犬。
- 精确避障需要带激光雷达（LiDAR）的 Pro 机型，目前还不能识别台阶和下沉落差。
- 描述画面、提问和读文字期间，避障语音会暂停；能否安全通行，请以避障提示和手中盲杖的探测为准。

你可以随时在设置的最下方重新查看这份说明。
