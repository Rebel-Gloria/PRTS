# 使用说明

PRTS 使用 iPhone 相机帮助你发现前方障碍，还可以描述眼前画面、回答提问、朗读文字，并播报周围的动作变化。

## 使用方式

- **开始避障**：轻点屏幕底部的“开始”，或在设置好操作按钮后按下操作按钮启动；也可以用 Siri 或轻点背面运行“开始 PRTS”快捷指令。使用旁白时，双指轻点两下也可开始。
- **停止避障**：按住底部主按钮 1 秒。开启“点按停止”，或应用检测到辅助触控、切换控制时，轻点主按钮即可停止。如果未检测到辅助触控，可在“设置”中开启“点按停止”。使用旁白时，双指轻点两下，或选中主按钮后轻点两下即可停止。
- **描述画面**：相机运行期间，短按一次相机控制按钮，即可听取眼前画面的简短描述。
- **语音提问**：按住相机控制按钮满半秒，听到提示音后说出问题，松手就会发送。首次提问需允许访问麦克风和语音识别。
- **流式字幕**：快速连按三下相机控制按钮开启，开启后会先简述周围环境，再持续播报画面中的动作变化；运行中再按一下即可退出。此功能需开启“允许使用云端服务”、在“通义千问”中保存 API Key 并保持联网。
- **读文字**：三指按住屏幕约 1 秒，听到提示后拿稳手机，PRTS 会在对焦稳定后自动拍照，朗读面前路标、纸张或物体上的文字。使用旁白时，请选中主按钮，上下轻扫选择“读文字”后轻点两下。再次三指按住屏幕、轻点主按钮，或使用旁白双指轻点两下即可退出。

## 按钮提示

- 若要按下操作按钮直接启动，请前往 iPhone 的“设置”>“操作按钮”，选择“快捷指令”，然后选定“开始 PRTS”；你也可以在“设置”>“辅助功能”>“触控”>“轻点背面”中选择“开始 PRTS”。
- 相机运行期间，按下任一音量键也会触发与相机控制按钮相同的拍照操作，暂不调节音量；如需用音量键调节音量，请先停止相机或打开“设置”。

## 设置选项

- **智能**：为“描述画面”、“语音提问”和“读文字”选择“本机”或联网服务。“读文字”还可选 Apple Vision，联网不可用时会自动改用本机识别；“流式字幕”固定使用“通义千问”。使用联网服务需开启“允许使用云端服务”并保存 API Key；关闭该开关会阻止新的云端操作，但进行中的请求和已开启的流式字幕会继续。选择“本机”时，照片和语音都留在本机处理；使用云端提问时，还可能使用 Apple 语音服务。
- **交互**：按需开关“低视力模式”、“点按停止”、“三指快速朗读面前文字”和“无画面模式”；支持激光雷达的机型还可开关“显示扫描网格”。开启“低视力模式”后会保留相机画面和各项智能功能，暂停深度感知与避障提示。
- **语言和语音**：开关“语音播报”，调整“语速”，或关闭“跟随系统语言”后单独选择“播报语言”。关闭“语音播报”只会静音状态和避障语音，你主动触发的描述、提问、流式字幕和读文字仍会正常朗读。

## 重要信息

- PRTS 是辅助工具，不能代替盲杖或导盲犬。
- 避障提示需要配备激光雷达（LiDAR）的 Pro 机型，目前尚不能识别台阶和落差。没有激光雷达的机型不会把估算的深度当作实测结果，也不会发出避障提示，但仍可使用描述画面、语音提问、流式字幕和读文字。
- 开始时振动两下，只表示相机已经启动，不表示前方已经探明或畅通。刚启动在测清前方之前会保持安静；任何时候没有听到提示，都不表示前方畅通。停止后再开始、读完文字返回，或关闭“低视力模式”回到避障时，请等待新的提示。
- 如果当前画面测不到地面，iPhone 不会提示“前方畅通”，也不会发出一般障碍或转向提示；只有手机朝向前方，且实测到极近的障碍几乎挡满整个画面时，才会单独提醒“障碍很近”。
- 如果一时没有测到新的深度，手机只能在刚探明的区域内短暂保持原有引导，最多约 2 秒。走出这片已探明区域后仍无法恢复引导时，手机会振动并提醒一次“暂时看不清”。
- 描述画面、语音提问，或打开“设置”和“使用说明”时，避障语音和振动都会暂停。使用流式字幕时，避障语音暂停，但仍可通过振动获得方向和受阻提示。读文字或开启“低视力模式”时，手机会暂停探测周围的障碍。
- AI 描述、回答和文字识别可能出错，前进前请结合避障提示和盲杖确认安全。

你可以随时在“设置”最下方轻点“使用说明”重新查看这份说明。
