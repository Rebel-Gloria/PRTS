# 使用说明

PRTS 使用 iPhone 相机帮助你发现前方障碍，还可以描述眼前画面、回答提问、朗读文字，并播报周围的动作变化。

## 使用方式

- **开始避障**：轻点屏幕底部的“开始”，也可以对 Siri 说“开始 PRTS”，或在“设置”>“辅助功能”>“触控”>“轻点背面”中选择“开始 PRTS”。
- **停止避障**：按住主按钮 1 秒。如果你打开了“点按停止”，或正在使用旁白，轻点或双指双击即可停止。
- **描述画面**：避障期间，按下任一音量键或轻点屏幕上的拍照按钮，即可听取眼前画面的简短描述。
- **语音提问**：按住音量键或拍照按钮，听到提示音后说出问题，松手就会发送。
- **流式字幕**：连按三下音量键或拍照按钮开启，开启后会持续播报画面中发生的动作；运行中再按一下即可退出。此功能需配置通义千问的 API Key 并保持联网。
- **读文字**：三指按住屏幕不动并保持手机平稳，PRTS 会自动拍照并朗读面前路标、纸张或物体上的文字。

如果你希望音量键照常调节音量，请前往“设置”>“交互”，关闭“音量键快捷操作”，改用屏幕上的拍照按钮。

## 设置选项

- **智能**：选择使用本机模型还是联网服务来描述画面、回答问题和读文字。关闭“允许使用云端服务”后，选择“本机”仍可按住提问。照片和提问都留在本机。流式字幕固定使用通义千问。
- **交互**：按需开启低视力模式（保留相机和智能功能，暂停深度检测和避障提示）、点按停止、音量键快捷操作、三指读文字以及无画面模式。
- **语言和语音**：开关语音播报，调整语速和播报语言。

## 重要信息

- PRTS 是辅助工具，不能代替盲杖或导盲犬。
- 精确避障需要支持激光雷达（LiDAR）的 Pro 机型，目前尚不能识别台阶和落差。
- 描述画面、提问和读文字期间，避障语音会暂停。AI 描述和回答可能出错，能否通行请以避障提示为准。

你可以随时在设置的最下方重新查看这份说明。
