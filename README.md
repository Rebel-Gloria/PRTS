# PRTS

**项目概述**：PRTS 是一款专为视觉障碍人群设计的离线视觉辅助应用。系统以端侧多模态大模型（如MiniCPM-O、MiniCPM-V等）为主要推理引擎，借助 Apple 芯片的 Metal 加速与 LiDAR 传感器，致力于为用户提供文字识别、空间感知、自然语言交互与主动提醒等核心能力，并在弱网或无网环境下保持完整功能可用。

### 一、 问题背景与用户分析

视觉障碍会严重影响人的生活、受教育、就业，还会加重家庭负担并限制其社会参与。现有的视觉障碍辅助工具（如导盲犬、专用视觉辅助设备、云端视觉模型）虽然在效果上可以极大方便视障人士的生活，但这些方案在成本、使用门槛和普及度上存在诸多局限，导致绝大多数视障人士仍然依赖导盲杖等较为落后的工具。

我们的目标用户即视觉障碍人群，由于受教育与就业受限，普遍存在经济困难、知识与技能缺乏的问题。视障人群亟需一款低成本、便携、隐私友好且无网可用的辅助工具。此外，对于弱视、近视、色盲等视力受限人群，市面上也缺少相关辅助工具，他们同样是本应用的潜在用户。

### 二、 相关竞品分析
传统导盲工具如导盲杖，虽然成本低、易获取，但能获取的信息非常有限，且使用极为不便。导盲犬有更强的能力，但训练与饲养成本极高，在绝大多数地方并不普及。

经过调查，目前市场上尚未出现成熟的离线视觉辅助方案。与本方案关联最密切的两条路线在实际应用中均存在明显短板：

1.  **专用硬件方案（如 OrCam、MyEye 等）**：传感器与算法深度融合，依赖专用硬件，定制度高，但也因此成本高昂。且后续软件维护不稳定，升级空间小，普及难度大。
    
2.  **纯云端方案（如 Seeing AI、Be My Eyes 等）**：依托云侧大模型能力实现较强识别，但伴随着较高的网络延迟、隐私风险以及持续的 API 调用成本。
    

而这正是 PRTS 诞生的初衷，我们希望平衡上述各类方案，借助端侧模型，在**成本、速度、便携性与普适性**四个维度上取得综合优势。

### 三、 可行性分析

项目的技术方案可行性建立在坚实的软硬件基础与前期的原型验证之上：

-   **技术原型与前期验证**：我们的方案灵感来源于团队成员何梓仪的毕业设计，该项目已基于 MiniCPM-O 模型构建了技术原型，并在 M 系列芯片、Snapdragon 芯片、Meta quest 设备和 iOS（基于wasm）上完成了移动设备和 VR 设备的验证。根据实际测试体验，其表现优秀，能够只凭借对话交互完成环境文字识别、室内语音导航等复杂任务，应当能够满足视障人士的日常活动需求。
    
-   **软硬件适配与优化**：我们计划重构其设计，优化其在移动设备上的运行表现。目标平台为 iOS（iPhone/iPad），充分利用 Apple 提供的 Metal 加速框架进行模型推理。面对 iPhone 所使用的 A 系列芯片更小的内存，我们可以选择适配更轻量的 MiniCPM-V 模型或正在适配的 JoyAI-VL-Interaction。
    
-   **多维度感知能力**：除视觉 RGB 摄像头外，系统将利用 iPhone 部分机型搭载的 LiDAR 传感器获取三维空间信息，实现避障和空间定位，并支持视觉与 LiDAR 的联合感知。
    
-   **灵活的模型架构**：系统开放接口以便用户选择不同的模型。即使内置的本地模型无法满足特定需求，用户也可以选择接入云端模型，或者接入在局域网其它高性能设备（如 Mac mini）上运行的模型。为保障安全，也可将 VLLM 与 YOLO 模型结合，兼顾语义理解与实时安全检测。
    

### 四、 App核心功能与创新点

我们的系统能够帮助视障人士克服日常生活中绝大多数因为视觉问题带来的不便，能够以对话的方式完成多种任务。

#### 1. 核心功能

-   **文字识别（OCR + 阅读）**：可阅读路牌、门牌、商品包装、药物说明书等，支持长文本识别，将物理世界的文字转化为语音播报。
    
-   **空间感知与导航**：支持方位识别，寻找教室、电梯口、卫生间等，指示物体位置。结合 LiDAR，提供更为立体的空间认知与避障引导。
    
-   **自然语言交互**：用户几乎无需任何专业知识或技能，只需如同与人类交谈一般和系统对话，即可完成指令下达和结果反馈，实现"开口即用"。
    
-   **主动提醒与预设任务**：支持预设任务（如等公交车、等红绿灯、检测指定物体）。系统可主动监测环境并在状态变化（如红绿灯切换、公交到站）时主动通知用户，从"被动等待查询"转变为"主动守护提示"。
    

#### 2. 产品创新亮点

-   **离线可用，隐私无忧**：我们的系统将能够安装并离线运行于较新的 iOS 设备中。数据无需离开设备即可完成推理，彻底摆脱网络依赖，保护用户隐私。
    
-   **零门槛低成本**：用户只要拥有 iPhone 或 iPad，就能免费或以少量一次性付费获取一套具有完整功能的视觉辅助系统。考虑用户特殊性，我们的系统将摒弃复杂菜单，确保所有功能与绝大多数配置可语音访问。无需后续付费与专业技能学习即可使用。
    
-   **弹性架构与个性化配置**：如有需要，用户可以选择接入云端模型，或随身携带高性能设备（如 Mac mini）运行大模型，将手机作为纯粹的交互终端。同时向用户开放感知模式（纯视觉/LiDAR/融合）和模型倾向（推理优先/检测优先）的自主配置。
    

### 五、 应用前景

-   **核心受众普及**：我们的应用将能够轻松安装至 iPhone 手机中，这将使得拥有 iPhone 的视障人士（全球约2.85亿视觉障碍人口）都可能愿意尝试，或许也会吸引更多视障人士购买 iPhone 手机。我们个人的愿望是将其推广至更多类型的设备（如 Apple Vision、边缘设备等）上，或引起其它厂商的跟进，以惠及更多人。
    
-   **拓展受众群体**：未来，在其它需要机器视觉辅助的场景下，应用凭借手机离线运行的优势，可为广泛用户带来快速低成本的服务。例如：
    
    -   老年人可以使用其辨认药品说明书上的细小文字。
        
    -   色觉障碍者可以使用其快速分辨商品的真实颜色。
        
    -   普通用户在弱光或陌生环境中也可利用其获取视觉信息。
        
-   **极端与特种场景延伸**：离线、轻量化这两个优势能带来意想不到的应用场景。我们的系统未来或许能装载于各种小型设备中，被用于家政服务、野外勘测、抢险救灾这类隐私敏感或缺少网络覆盖的特殊环境。

### 六、目前进度
PRTS 当前默认运行“第一阶段完全离线基础感知”：单一 ARKit 会话、LiDAR scene depth/置信度、mesh floor prior、本地三态栅格、近场障碍与短距离左／中／右观测候选通道、同源 SwiftUI/语音/触觉反馈。

当前实现局部路线引导，不接入目的地服务、GPS 或 ARWorldMap，不连接本地 VLM、Omni 或 vLLM。新增按需云端拍照描述，与路线规划分离，默认不发送图片；见 [拍照描述](docs/PHOTO_DESCRIPTION.md)。原始三态栅格保留测量含义；独立规划栅格开放全部非确认障碍区域。路线以世界坐标保存在当前会话内。
