# 接续状态

本文记录首页交互与非盲模式的最终行为、验证结果和待决定事项。

## 当前行为

- 首页提供手动开始和按住 1 秒停止。设置中的“点按停止”默认关闭，辅助触控或不便长按的用户可开启；保留旁白操作。
- “开始 PRTS”快捷指令只启动相机或退出文字识别，不停止已运行的相机。
- 进入设置时相机继续运行，避障反馈暂停。
- 进入后台暂停采集并保留用户的运行状态；返回前台仅恢复用户已开始的会话。主动停止后不自动恢复。
- 非盲模式默认关闭，开启需确认；保留描述、提问与文字识别，屏蔽避障语音与振动。
- 六份使用说明及相关文档已同步更新。
