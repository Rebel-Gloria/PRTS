# 使用与无障碍

本文说明日常操作、设置和替代交互。开发调参及采集选项见[开发指南](../development.md)。

## 常用操作

| 功能 | 普通操作 | 替代操作 |
|---|---|---|
| 开始或停止引导 | 点击开始；按住停止 1 s | 旁白两指双击、主按钮激活或“停止”操作；Siri 与快捷指令 |
| 描述画面 | 短按拍照按键 | 屏幕按钮的旁白双击；“描述画面”快捷指令 |
| 语音提问 | 按住拍照按键说话，松开发送 | 旁白“开始语音提问”“结束语音提问并发送”；辅助触控或切换控制下两次点击 |
| 朗读文字 | 三指长按 0.8 s | 主按钮的旁白“读文字”操作 |

拍照按键按设备能力分配，详见[拍照描述](photo-description.md)。旁白会接管多指手势，读文字应通过转子切换到“操作”，上下轻扫选中后双击。朗读期间可轻点主按钮或使用旁白两指双击退出。

辅助触控（含停留控制和眼动追踪）或切换控制开启时，主按钮可点击停止，无须持续长按。语音控制可通过 `accessibilityInputLabels` 匹配“开始”等操作。App Intents 的开始、停止和描述画面可分配给 Siri、快捷指令、操作按钮或轻点背面。

## 日常设置

| 设置 | 默认值与作用 |
|---|---|
| 智能设置 | 默认本机离线；可选千问、DeepSeek 或自定义服务，配置 API Key、上传授权与提问权限 |
| 提问时深度思考 | 默认关闭，仅千问和 DeepSeek 显示；影响长按提问，可能增加等待时间 |
| 音量键快捷操作 | 默认开启，仅无相机控制按钮的设备显示 |
| 三指快速朗读面前文字 | 默认开启；关闭后同时隐藏旁白“读文字”操作 |
| 识别服务 | 默认本地 VLM，可选 Apple Vision 或远端 API |
| 语音播报与语速 | 默认开启、正常语速；主动请求的描述和回答不受自动播报开关影响 |
| 语言 | 默认跟随系统，可选中文或 English |
| 无画面模式 | 默认关闭；开启后停止画面绘制，避障计算与反馈继续 |
| 扫描网格 | 默认关闭，仅 LiDAR 设备显示；用主题绿色绘制环境网格及规划路线 |
| 振动提示 | 默认开启；关闭后停止全部振动，包括方向提示 |

本机服务隐藏 API Key 和上传开关。相机控制按钮在支持的设备上始终可用。普通构建没有独立的避障引导或方向振动开关。

设置键分别包括 `photoDescription.questionThinking`、`photo.hardwareButtons`、`ocr.threeFinger`、`ocr.service`、`display.noPreview` 和 `display.scanMesh`。API Key 存钥匙串，其余选择主要由 UserDefaults 和 `SpeechManager` 管理。

## 旁白与语音

开启旁白后，相机开关、设置切换等界面状态交由旁白朗读，App 避免重复播报。避障和拍照回答仍由 App 输出，并通过 `prefersAssistiveTechnologySettings` 跟随旁白音色和语速。

拍照过程中的“正在描述”“正在朗读”状态会告知用户。错误信息使用 `.callout` 字号，旁白开启时额外朗读一次。相机画面、渐变和装饰图标不参与旁白导航。

## 大字体与画面显示

字号达到 AX1–AX5 时，主页采用可滚动单列布局，主按钮固定底部，状态面板允许换行，开发指标自动隐藏。设置入口保留齿轮图标，长按可使用系统大型内容查看器。未开始引导时显示操作提示卡，旁白作为整段朗读；启动过程使用系统加载动画。

增强对比度或降低透明度时，拍照按钮不透明度由 0.25 提高到 0.85，并增加深色背景。iOS 26 及以上的液态玻璃由系统适配，主按钮使用实色背景和深色文字。

无画面模式不创建 `CameraMetalView`，主页显示“无画面模式 · 避障照常运行”。分析、语音、振动、拍照和 DIAG 继续运行，绘制 FPS 与 `displayedFrameID` 为 0。开发设置中的“隐藏相机画面”只隐藏底图，叠加层仍以 30 FPS 绘制，作用不同。旁白用户也可通过三指三击开启系统屏幕幕帘。

## 适配范围

设置、拍照设置和拍照按钮提供中英文，开发者选项暂为中文。开发版图例仍主要以颜色区分地面和障碍，尚未提供线型替代；横屏下部分布局可能拥挤。

实体拍照按键已在 iPhone 17 Pro Max 上验证。旁白实际使用、Magic Tap、辅助触控与眼动追踪、Siri 中文识别仍需进一步真机和用户验证，状态见[验证结果](../validation.md)。
