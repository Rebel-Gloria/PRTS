# 没有 LiDAR 的机型

没有 LiDAR 的 iPhone 用 Apple 提供的 Core ML 版 Depth Anything V2 从画面估算深度，再用 ARKit 的特征点和地面平面换算成米。估出来的深度只用来显示和画路线，不当作可靠的测距，确认不了哪里能安全通行。

## 什么时候走这条路

- 设备不支持 `sceneDepth`：强制走无 LiDAR，不能关。按能力判断，不按型号猜。
- 有 LiDAR 的设备：开发版里可以打开"模拟无 LiDAR 设备"来测试这条路。这只是换了 App 用的数据，ARKit 内部是否用了 LiDAR 辅助无法排除，所以最终还要在真正没有 LiDAR 的手机上验证。
- 切换时会停掉并重建 ARSession，清空所有旧结果，两种模式的数据不混用。
- 这条路只开水平和竖直平面检测，不请求 `sceneDepth` 和场景网格。

## 模型

- `apple/coreml-depth-anything-v2-small` 的官方 `DepthAnythingV2SmallF16.mlpackage`，固定在仓库版本 `cfef6f6f2a70783dedc0bfae40cecbc2052285d3`。约 49.8 MB，SHA-256 在 `PRTS/Spatial/Models/provenance.json`，Apache 2.0 许可和模型卡都在同一目录。
- 输入是 518×392 的图像，输出是 518×392 的相对逆深度，按帧归一化，**单位不是米**。模型卡上写的 518×396 和实际包不符，代码读的是包里的描述。
- 画面转正后等比例留边送进去，输出再映射回相机方向的分析图（256 宽）。不裁掉画面边缘。
- Core ML 用 `.all`，由系统选择计算单元。

## 换算成米

模型给的是相对值，要找独立的参照来换算：

- ARKit 的 `rawFeaturePoints` 投到同一帧上，得到"模型值 ↔ 真实深度"的配对；
- 被 ARKit 分类为 floor 的稳定平面，用射线求交补充配对。

拟合 `1/z = a × ((q - center)/spread) + b`，用 RANSAC 加精修。一帧要满足这些才算拟合成功：

- 至少 16 对，分布在 4×4 图像分区中的至少 6 区；
- 参考深度在 0.3–8 m，深度跨度（P90−P10）大于 0.35 m；
- 斜率为正，至少 65% 的配对误差小于 15%，内点的中位残差小于 8%。

还要连续 3 帧都成功，而且跨帧检查通过：上一帧的参考点投到当前帧，至少 16 个、覆盖 6 区，65% 以上误差小于 20%，中位残差小于 8%（有 feature ID 时还要求点的漂移不超过 max(8 cm, 1.5% 距离)）。帧间隔要小于 0.5 s，位移不超过 0.75 m。

当前帧拟合失败就撤掉米制输出，从头确认，不沿用旧系数。只保留拟合范围附近（最多外扩 10%）的深度。

这些门槛只是质量筛选，不代表测距误差。真实精度要拿卷尺测。

## 地面参考

- 从 `ARPlaneAnchor` 选地面：法向向上、倾角 ≤12°，在相机下方 0.45–2.3 m；floor 至少 0.3 m²，未分类平面至少 0.7 m²。优先 floor；桌面等其他分类的平面不用。
- 同一平面要稳定 0.4 s；高度跳变超过 5 cm 或法向变化超过约 3° 就重来。
- 短暂找不到平面时，最多沿用 2 s（位移 ≤1 m）。沿用的参考只能配合当前帧已校准的深度显示，不提供新的拟合配对。
- 未分类平面上画的蓝色只表示"在参考面附近"，不表示确认的地面。

## 显示和限制

- 尺度没确认时，热图标注"相对深度"；确认后标注"预测深度（米）"。
- 模型没有置信度，置信度图层显示不可用。另存一份 `predictionSupport` 掩码，它只是 App 的几何筛选结果。
- `VisibilityDepth` 不用预测深度确认净空，`PredictedGeometry` 会撤掉所有候选格：这条路不输出确定的障碍距离，也不生成候选通道。
- 不做台阶和落差判断。

## 诊断

- `prediction.jsonl`：模型版本、相对深度附件、平面快照、尺度配对、拟合结果、拒绝原因、各阶段耗时（加载、预处理、推理、映射、平面、尺度、显示）。
- 尺度通过后的深度也写进 `analysis.jsonl`，标明来源是预测。
- 读取：`python3 scripts/read_diag.py <目录> --extract-prediction 1:123 --output <目录>`，格式见 [DIAG 记录格式](../guides/diag-format.md)。
- 离线重放尺度确认：`Experiments/SpatialProbe/scripts/replay_monocular.swift`，读原始相对深度、内参、位姿和配对，跑生产代码里的 `MetricScaleTracker`。它衡量的是"尺度能不能确认"，不是测距准不准。

## 还要实测的

在真正没有 LiDAR 的 iPhone 上：世界跟踪和平面能不能用；横竖屏下热图和画面是否对得上；移动、转身、遮挡、弱光、室外时尺度能否确认；用卷尺测地面高度和障碍位置，每项至少 3 次；连续运行 30 分钟。
