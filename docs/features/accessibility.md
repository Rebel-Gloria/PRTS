# 无障碍

PRTS 的主要用户是视障和低视力人群，所以旁白、大字体、不方便按住屏幕的用户，每一种都要能完整用下来。这份文档说明现在每种情况是怎么处理的，以及还没做完的部分。

## 旁白（VoiceOver）

- **不重复播报**：旁白开着时，界面状态（相机开关、进入设置等）只通过旁白播报，App 自己的语音不再说一遍（`SpeechManager.announce` / `announceCameraState`）。避障提示和拍照回答仍用 App 语音，但语速和音色跟随旁白设置（`prefersAssistiveTechnologySettings`）。
- **停止**：主按钮的激活操作和"停止"操作会直接停止，不用按住。普通触摸仍是按住 1 秒停止，防止误触。
- **Magic Tap**（两指双击）：在主页任何位置开始或停止。
- **拍照提问**：拍照按钮上有"开始语音提问""结束语音提问并发送"两个操作。双击等于短按。
- **读文字**：旁白会接管三指手势，所以主按钮上加了"读文字"操作。
- **进度播报**：拍照描述的"正在描述""正在朗读"等状态，旁白开着时会播报出来。
- **错误**：错误信息用 `.callout` 字号，放在玻璃面板里；旁白开着时额外播报一次。
- 相机画面、渐变和装饰图标都对旁白隐藏。

## 大字体和低视力

- 字号调到辅助功能大小（AX1–AX5）时，主页换成单列布局（`ContentView.largeTextLayout`）：
  - 整页可以滚动，主按钮固定在底部；
  - 设置按钮只显示齿轮图标，长按弹出系统的大型内容查看器；
  - 状态面板占满整宽，文字可以换行（还没开始时不显示状态面板，由操作提示卡代替）；
  - 开发叠加层隐藏。
- 主页还没开始时显示一张操作提示卡（开始、轻点中间描述、三指长按读文字），旁白把它当一整段读。加载中（启动相机、读文字等画面）用系统转圈动画，不显示帧数之类的技术数字。
- 打开"增强对比度"或"降低透明度"时，拍照按钮的不透明度从 0.25 提到 0.85，并加深色底。
- 液态玻璃（iOS 26 及以上）由系统自动适配"降低透明度"和"增强对比度"。主按钮是实色底加深色字。

## 不方便按住屏幕的用户

| 方式 | 适合谁 | 怎么用 |
|---|---|---|
| 旁白、语音控制、切换控制的"停止"操作 | 读屏、语音、开关用户 | 直接停止 |
| 辅助触控（含停留控制、眼动追踪）或切换控制开着时 | 不能按住屏幕的用户 | 主按钮显示"停止"，点一下就停；多出一个"开始/发送语音提问"按钮，点两下代替按住提问 |
| Siri、快捷指令、操作按钮、轻点背面 | 所有人 | App Intents 提供开始、停止、描述画面三个操作 |
| 音量键和相机控制按钮 | 所有人 | 拍照描述，见 [拍照描述](photo-description.md) |

## 文案和本地化

- 设置页、拍照设置页和拍照按钮的文案都在 String Catalog 里，系统语言是英文时不会听到中文。开发者选项只有中文。
- 主按钮加了 `accessibilityInputLabels`，语音控制里说"开始"能匹配上。

## 还没做的

- 开发版图例只靠颜色区分（"蓝：地面 · 红：障碍"）。改线型要动 Metal 渲染器，还没做。
- 横屏时顶栏和主按钮会挤在一起。要不要锁定竖屏还没定。

## 还没在真机上试过的

- 旁白下的播报去重和"停止"操作，需要视障测试员实际用一遍。
- Magic Tap、辅助触控和眼动追踪下的点一下停止、Siri 的中文短语。

实体按键拍照已在 iPhone 17 Pro Max 上试过：ARKit 运行时系统照样把按键事件交给 App，相机控制按钮也不会跳到系统相机。
