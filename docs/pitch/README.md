# 宣传材料制作说明

本分支维护比赛演示文稿和宣传视频。内容围绕使用场景、现有功能和验证结果展开，不包含成员姓名、个人履历或毕业设计介绍。功能状态以工程文档为准，旧配音和截图不能直接作为当前版本说明。

## 表达与交付

演示面向比赛评委，约 3 分钟，建议 14 页，中文、16:9，设计尺寸 1920×1080。交付 Keynote 或 PowerPoint，并将讲稿写入演讲者备注。

每页表达一个重点，以具体功能和实测结果说明项目。避免口号、连续排比和“赋能”“颠覆”等宣传用语。测试数字必须附日期、设备和测量对象；示意路线明确标注，不暗示为真实导航结果。

## 视觉与素材

| 元素 | 要求 |
|---|---|
| 配色 | 暖黑 `#0D0C0A`、暖白 `#EDE8E0`；次要文字 `#8C857A`、`#4A463F` |
| 强调色 | 薄荷绿 `#40F2C4` 用于功能、路线示意和数字；暖橙 `#E8B77A` 用于障碍；每页最多一种 |
| 字体 | 标题 Songti SC，正文 PingFang SC，常规或细体；重点数字可用中粗，不用 SF Pro |
| 字号 | 标题 60–80 pt，大数字 160–240 pt，正文 28–36 pt，出处 14–16 pt |
| 版式与动画 | 留白、左对齐；大数字可居中；使用淡入、溶解或神奇移动，不用飞入、弹跳和旋转 |
| 截图 | 放入简洁手机外框；不出现苹果 logo 或暗示 Apple 官方出品的元素 |

照片可加暗色渐变提高文字对比度。绿色只作为视觉强调，不表示已经确认安全通行。

| 素材目录 | 内容与用途 |
|---|---|
| `brand/` | `app-icon-1024.png`、`app-logo-prts.svg`、`app-logo.svg` |
| `photos/` | 2026-10-28 晚 iPhone 17 Pro Max 实拍，720×960；人行道、车辆、走廊和地铁站入口 |
| `screens/` | 1320×2868 真机截图；使用前核对当前界面 |
| `visuals/` | 1920×1080 透明 PNG，含 `cane-reach`、`phone-sight`、`phone-sight-points`、`sound-and-nudge` |
| `clips/` | `street1.mp4`、`street2.mp4`、`station.mp4`、`indoor.mp4`，720×960，约 7–8 s，无声 |

点云来自实地录像单帧的边缘点，路线为绘制示意。`settings-walk-width.png` 含已撤回设置，不用于介绍当前功能。缺少可用的避障运行截图、比赛名称和联系方式时，标为待补；不补写个人资料。

## 视频工程

视频使用 `Marketing/video/` 中的 Remotion 工程，现有分镜约 2 分 52 秒。`src/Film.tsx` 管理画面与时间，`src/Visuals.tsx` 导出透明示意图，`vo.txt` 是实际配音输入，`prepare.sh` 生成素材。`public/`、`out/` 不提交 Git。

```sh
cd Marketing/video
npm install
zsh prepare.sh <2026-10-28 DIAG目录>
npx remotion render src/index.ts PRTS out/prts-draft.mp4 --concurrency=2 --crf=20
npx remotion still src/index.ts Visuals out/kit/visuals/phone-sight.png --frame=1 --image-format=png
```

草稿配音使用 `say -v Tingting -r 165`，正式成片可换真人。配乐为《Clean Soul》，原记录使用 CC BY 4.0，保留素材和片尾所需署名。

| 时间 | 现有分镜 |
|---|---|
| 0:00–0:34 | 晚间测试开场，人行道实拍 |
| 0:34–1:02 | 导盲杖近处感知、手机补充信息的示意 |
| 1:02–1:38 | 点云、路线、声音和振动 |
| 1:38–2:06 | 画面描述与文字朗读 |
| 2:06–2:32 | 地铁站入口与已知限制 |
| 2:32–2:52 | 测试邀请、项目标识和素材署名 |

制作新版本前，核对 `vo.txt` 和 `Film.tsx` 中的旧说法，尤其是通行能力、振动方式和联网条件。本次文档合并未重新生成视频或配音。

## 数据与能力边界

性能数据统一引用[验证结果与已知问题](../validation.md)：iPhone 17 Pro Max、2026-10-28 实地记录的分析频率 10 Hz、延迟 p95 47.8 ms、规划 p95 0.5 ms、内存峰值 732 MB，系统热状态 nominal。热状态正常不能改写成“不发热”，p95 也不能写成每次耗时。

原素材引用的 1731 万视障人士来自央视《东方时空》2024 年 4 月转引资料，约 410 只在岗导盲犬来自新华社 2025-05-02 报道；不能写成当前实时统计。346 个测试函数是 2026-10-29 的代码计数，不等于全部测试已通过。

当前模型和识别耗时使用验证文档中的对应结果。旧 Apple Vision“一页约 0.7 s”不代表当前本地 VLM 全流程。本地模型接入源码或测试机运行成功，也不等于已公开上线。

不声称已获得长期视障用户认可，不编造准确率，不将台阶检测、红绿灯识别或目的地导航写成已实现。功能与操作以[项目首页](../../README.md)及其链接文档为准。
