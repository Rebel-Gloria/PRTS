# 比赛宣传：视频脚本和素材

给比赛评委看。PPT 交给专门做 PPT 的模型来做，要求和逐页内容见 [PPT 制作说明](ppt-brief.md)。视频约 3 分钟，在 `Marketing/video` 里用 Remotion 做。

## 文件

`Marketing/video/` 下：

- `src/Film.tsx`：视频。
- `src/Visuals.tsx`：给 PPT 用的去掉文字的抽象示意图，透明背景。
- `vo.txt`：配音台词。
- `prepare.sh`：生成 `public/` 下的全部素材：实拍片段、静帧、颗粒、配音、配乐、点云。

`public/` 和 `out/` 都不进 git，需要时用脚本重建：

```sh
cd Marketing/video
npm install
zsh prepare.sh <2026-10-28 DIAG 目录>
npx remotion render src/index.ts PRTS out/prts-draft.mp4 --concurrency=2 --crf=20
npx remotion still src/index.ts Visuals out/kit/visuals/phone-sight.png --frame=1 --image-format=png
```

配音草稿用 `say -v Tingting -r 165`，定稿建议换真人。配乐用 Kevin MacLeod 的 "Clean Soul"（incompetech.com，CC BY 4.0），片尾已署名。

## 视频分镜（约 2 分 52 秒）

风格：暖黑底，宋体标题，胶片颗粒。手机"看到的东西"画成抽象的点和光：点取自实地录像一帧的边缘，路线是示意。

| 时间 | 画面 | 配音 |
|---|---|---|
| 0:00–0:11 | 日期，"十月底，一个晚上。" | 十月底的一个晚上，我们拿着手机，在小区和街上走了几圈。 |
| 0:11–0:34 | 右侧是人行道实拍，左侧是字 | 人行道上停满了电动车和共享单车……只能拿着杖，一点一点去碰。 |
| 0:34–0:52 | 黑暗里，杖尖每点一下，只亮起脚前一小片点 | 中国有一千七百多万视障人士…… |
| 0:52–1:02 | 光从脚下铺开，整条街的点都亮起来 | 我们想做的事情很简单：让手机替他先看一眼。 |
| 1:02–1:24 | 点云里，障碍是暖色，一条薄荷绿的路线穿过空当 | 手机背面的激光雷达，每秒量十次前面的路…… |
| 1:24–1:38 | 一圈圈声波，屏幕左边缘亮起震动 | 然后用声音告诉你，再用左右两边的震动…… |
| 1:38–2:06 | 走廊照片化开，散落的字聚成一句描述；再聚成纸上的一行字 | 想知道面前是什么……不用联网，照片也不用传出去。 |
| 2:06–2:32 | 地铁站口实拍 | 它现在还不完美……看漏了不行，乱报也不行。 |
| 2:32–2:52 | "想请视障朋友跟我们一起走"，图标，署名 | 接下来，我们想请视障朋友跟我们一起走，一起改。 |

视频的语气还要按 PPT 的基调调整：多讲做成了什么，讲不足的部分压缩到一段。
