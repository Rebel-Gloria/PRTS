# 地面与突起表面建模（2026-09-27）

## 使用

设置 → 几何叠加 → **表面建模：蓝地面／红突起**，默认开启。

- **蓝色**：当前高置信度深度支持、贴合已确认局部地面的可见表面。
- **红色**：相对局部地面法向的高度达到默认 **5 cm**、具有空间支持的可见突起表面。箱子、石块、凸起地形、桌面等不必先获得 ARKit 物品语义类别。
- **未知**：地面未确认、低置信度、缺深度、空间支持不足、数据过期等情况不生成蓝／红表面；俯视栅格仍显示未知。

蓝色只表达“观测到了地面表面”，不表示身体净空充分或该处可通行。红色只表达高于参考地面的观测几何；**不保证与地面接触，不把桌面误称为落地物，不是完整物体识别**。悬空障碍也可为红色。

## 判定与建模

实现位于 `Core/Sources/SpatialCore/SurfaceModel.swift`，在串行分析队列内运行：

1. 要求 floor 先验和当前深度支持的地面连续确认至少3帧；方向稳定，使用未经平滑的 `sceneDepth`。
2. 将高置信度有效深度反投影至世界坐标，再投影到局部地面参考系。高度沿地面法向量取，不直接使用世界 y 或画面下半区。
3. 地面类：`abs(height) <= planeTolerance`（默认3 cm），相应格至少3个直接地面样本。没有把无限参考平面填蓝。
4. 突起类：`height >= max(0.05 m, planeTolerance + 0.02 m)`，且对应当前帧格为有至少3点支持的障碍。量程仍限于当前局部窗口和身体检查高度。
5. 只在同类、连续的有效深度小块上生成三角面，顶点保留真实三维高度。不是把红色区域压平到地面的旧二维栅格。
6. 每个抽样小块的**所有原始像素**都必须有效并属于同一类别。低置信度孔洞、未抽到的坏点、地面／突起边界均不跨越。
7. 额外限制小块轴向深度跳变≤8 cm、三角边长≤15 cm，并剔除退化三角形。每帧最多12,000三角面，通过增大建模采样步长控制预算。
8. 不补封闭体积、背面、底面或遮挡区域。模型只有当前可见表面，没有跨帧累积残影。

5 cm 是突起**显示建模阈值**，不是可靠检出的最小物体尺寸，也不是安全阈值。原有栅格障碍判断仍使用更保守的非地面证据：例如4 cm凸起可能不生成红色模型，但不会因此被改成蓝色地面／可通行。

## 显示与失效

- 蓝／红模型与RGB共用相机内参、姿态和完整视野映射。
- 开启时替代旧 ARKit floor 填色及二维栅格投影，避免历史分类把凸起盖成蓝色或青色候选带遮住模型。相关旧显示开关暂不可选；关闭新模式后可切回。
- 俯视图仍区分灰未知、红障碍、青候选；候选段仍是黄色，不因新的颜色层改变通道判定。
- 可独立启用 ARKit 分类线框作比较；它是另一种分类来源，不是新模型判定的真值。
- 模型使用最大250 ms、epoch／参数版本、追踪与生命周期门控。正常追踪的平移／转向不再关闭蓝红模型；方向稳定性仅影响候选通道和方向距离。冻结、停止、后台和会话失效时不保留实时模型。

## 数据与性能

- `AnalysisResult.surfaceModel` 保存当前三角面与摘要，是可选字段，旧的无该字段分析样本仍可解码。
- `frames.jsonl` 仅记录 `surfaceModel` **摘要**：蓝／红面数、阈值、最高观测突起高度和实际建模步长，避免每个日志帧保存完整网格。
- 手动同步样本的 `analysis.json` 保留完整模型，继承同帧来源／时间／epoch。没有同帧分析时不伪造模型。
- `stageMilliseconds.surfaceModel`、CSV的 `surfaceModelMS` 和HUD分别显示建模耗时，离线报告纳入统计。
- 不依靠更多排队帧提高密度，保持最新帧优先的有界调度。

## 验证与限制

新增合成测试：平地、凸起物品实际高度、无可靠地面、低／缺置信度、4 cm灰区、孤立异常点、粗采样内坏点、跨帧证据隔离、倾斜地面和旧样本兼容性。

真机请在受控条件下用平地、5/10/25 cm箱体或凸起物分别检查蓝／红区，与卷尺独立比较，保存手动样本。台阶、落差、透明／反光物、细杆的可靠检测仍未实现；未扫描表面不补全。

## 障碍和上方红色阻挡柱

在蓝／红实测表面的基础上，默认再开启 **“障碍及上方阻挡柱（红色）”**：

- 当前已确认障碍格按4邻接组成连通组，至少2格、每格至少3个有效点、合计至少6点，最高观测点达到突起高度阈值。
- 几何包络 `sum(格面积 × 该格最高观测高度)` 至少0.001 m³（1 L）。这是10 cm栅格分辨率下的几何支持门槛，不是测得物体的材质实心体积；桌面下方是否实心／是否接地未被确认。
- 只对该组实际有支持的格生成红柱，**从地面向上延伸至身体检查高度**（默认1.8 m；若格内观测顶更高，不把模型裁到该点以下）。阻挡柱尺寸可随设置中的身体检查高度变化。
- 物体实测表面为深红，上方为半透明红色禁入空间，附红色轮廓；该虚拟柱使用诊断叠加显示，不作为已观测占用写回传感器证据。
- 不能通过抬高通道来跨过地面障碍；该足迹本来就是障碍，原有身体足迹膨胀／通道禁入仍保持。
- 不把整个连通组的外接矩形填红。L形缺角、两个物体之间的未知格仍保持未知，不被模型补成实体或可通行。
- 孤立点、仅单格的不足支持、地面未确认不会生成红柱；这些区域原有疑似／障碍状态不被清空。
- 每个新结果仅由当前证据重建，物体移开后不能保留旧红柱；追踪失效或过期时撤销；仅方向变化时继续使用当前深度重建，通道另行暂停。

日志 `surfaceModel.blockingVolume` 摘要包含红柱格数、支持组数、包络门槛、支持包络量和名义高度；手动样本完整模型中的同名字段包含每柱的格索引、实测最低／最高高度及虚拟柱顶。

红色“上方空间”的显示限定在人体检查范围，不表示无限高度，也不声称空气是实体。要检查更高空间须调整设置并重新取证。
