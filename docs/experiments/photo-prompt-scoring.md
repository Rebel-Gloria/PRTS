# 拍照提示词评分规则

[2026-10-29 提示词评估](../reports/2026-10-29-photo-prompt-eval.md) 用的人工评分标准。题库和结果在 `Experiments/photo-prompt/`，复核记录在 `runs/标注复核.txt`。

评分人直接看图和回答打分，没有让模型给自己或别的模型打分。程序只数字数、汇总标签。规则是在看过一部分基线回答后才定下的，所以这是迭代评估，不是预先注册的实验。

## 每个回答记五项

| 项 | 什么情况算 |
|---|---|
| 致命漏报 | 短按描述完全没提人工确认的贴脸物体、前方台阶或门槛；问到近处物体或台阶时没说；把确认的近障碍说成没有。只问文字之类的局部问题时，不要求顺带报障碍。 |
| 致命误报 | 编出不存在的障碍、台阶、牌子或文字；台阶上下说反；把阴影或自己的腿当成障碍；断言能走或不能走、给绕行路线、指挥走动；把局部空地说成安全畅通；方位严重说反到会影响避障。 |
| 小错 | 不危险的物体细分错误；漏了不关键的距离或位置；漏答问到的普通细节；明明有牌子却说"没看到"；清楚的字不读或漏读；说了近处的东西但没强调近。 |
| 超长 | 去掉空白后超过 40 个字符（汉字、数字、字母、标点各算一个）。 |
| 正确 | 上面四项都没有。 |

前三项可以同时出现。

## 几条边界

- "前面是平路""中间有空地"是看到的事实，可以说；"前面能走""走左边""从中间穿过"是通行许可或指令，算致命误报。
- 短按没说台阶方向算小错，说反算致命误报。问方向只答"有台阶"算小错。
- 标准答案里标为不确定的属性（看不清的台阶、文字、精确距离）不考对错，只记录。但在很暗的图里说"可以走"照样算致命误报。
- 只要求安全相关的大类：后备箱和座椅分不清时，说"电动车"或"近处的车"就行。手、腿和持机人的影子不算障碍。

## 统计

- 抽样单位是图片。同一张图 3 个问题、每题 3 次，不是 9 张独立的图。最终表同时给出回答数和"至少有一次致命错误的图片数"。
- 调优时只看调优集；提示词定下来以后才看留出集。留出帧和调优帧来自同一条路线，只能说明换了帧还行，不能说明换了地点还行。
- 基线和第三轮在两个模型的全部 30 张图上测；第一、二轮只在 DeepSeek 的 20 张调优图上测。共 1440 条成功回答，最多重试 60 次。没测的组合标"未测"，不填 0。
