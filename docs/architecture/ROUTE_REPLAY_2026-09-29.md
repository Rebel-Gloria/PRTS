# 2026-09-29 晚间：滚动直线与避障回放优化

## 实施范围

保持原目录、单一 ARSession、后台队列、主页面和主题。未修改采集、地面拟合、置信度阈值、显示坐标变换、身体净空判定或 PathClearance 的碰撞数学。未安装到真机、未提交远端。

## 算法改动

1. **规划脱离显示网格**：新增 RoutePlanningGrid，直接读取当前帧地面采样和占用。显示用三角形的边长上限、深度跳变、九子点覆盖不再重复限制路线。未观测单元仍不加入路径。
2. **滚动贪心直线**：沿世界参考线，以栅格边长的四分之一为步长推进到连续支持区域的最远点（当前范围默认4m）。不再被旧目标点截短；目标ID稳定，点位前移，避免每次延长重复播报。
3. **匹配实际碰撞宽度的预避障**：近距1m三角区保留，但不再是唯一入口。前方规划带按总宽0.5m扫掠，已测障碍侵入即规划侧向路线。避免“足迹碰撞否决了直线，但窄三角区不触发绕行”的规则冲突。
4. **分离障碍与入口恢复**：优先处理最近的独立占用分量，不把远墙与近物合并成一个大障碍。中央入口堵塞时搜索可连接的侧向首个观测入口；已选侧保留，旧入口或终点失效时同侧重算。
5. **回归原线与前缀保留**：小障碍优先回归原线，观测不足时允许侧向观测段；远端暂时没有绕行空间时，保留到障碍前的有效直线前缀。所有搜索与化简仍经过完整宽度碰撞检查。
6. **局部地面一致性**：在当前相机位置比较新旧参考平面高度，避免轻微倾角在远处旧原点外推成13–14cm冲突。局部一致时重投影路线高度、保留方向；真实局部高度跳变仍撤销。
7. **绘图与方向分开**：已有地面参考时，几何规划不额外等待方向稳定；方向振动仍独立门控。主动转向不再要求观测起点距脚下≤1m，避免胸前持机盲区阻断3秒计时。

## 同输入回放方法

使用今晚4组 Dev Capture 的468个已保存采样。每帧读取完整 AnalysisResult、同期深度、位姿和当时参数。基线可执行文件在算法修改前保存；新旧各按完全相同的epoch、帧号、时间戳和顺序运行。没有重新采集或改写现场数据。
这是低采样、开环规划对比：没有补出未录制的10Hz中间帧，没有重新运行ARKit或地面分析；用户也没有实际沿新路线行走。因此不能将输出比例当作实机安全率或UI显示比例。
