# 交互与设置规格

本文面向开发者和测试人员，说明 PRTS 的交互手势、按键仲裁时序、前后台反馈策略、设置项与无障碍适配。面向终端用户的操作指南位于 `PRTS/Features/Settings/UserGuide/`；架构边界、空间感知与视觉识别实现请参阅[工程架构](architecture.md)、[空间感知](spatial.md)和[图像与文字识别](vision.md)。

## 交互方式

| 功能 | 标准操作 | 替代与无障碍操作 |
|---|---|---|
| 开始避障 | 轻点主按钮，或运行“开始 PRTS”快捷指令 | 旁白双指双击；Siri、轻点背面或操作按钮 |
| 停止避障 | 按住主按钮 1 s；开启“点按停止”后轻点 | 旁白双指双击，或主按钮的“停止”自定义操作 |
| 描述画面 | 短按拍照按键（松手早于 0.5 s） | 旁白双击屏幕拍照按钮 |
| 语音提问 | 按住拍照按键 0.5 s 后说话，松手发送 | 旁白“开始语音提问”和“发送语音提问”；辅助触控或切换控制下轻点两次 |
| 流式字幕 | 连按三下拍照按键，运行中按一下退出 | 使用屏幕拍照按钮或实体拍照键 |
| 读文字 | 三指按住屏幕 0.8 s | 主按钮的旁白“读文字”操作，或运行快捷指令退出 |

操作按钮、轻点背面与 Siri 共用 `ToggleGuidanceIntent`（为兼容用户已保存的快捷指令保留原类型名）。该快捷指令在读文字期间触发时会退出读文字并恢复原相机状态，其余状态用于启动避障。

## 避障状态提示

正常开始避障时不播报“初始化中”，仍以两下振动确认相机已启动。首次确认前没有路线提示。有当前实测地面时，首个“前方畅通”需要至少 0.5 s 的连续新观测，反复轮询同一结果不计时；已确认的障碍不必等待这段时间。相机权限和错误提示不受此规则影响。

当前画面测不到可用地面时，默认不发出新的畅通、障碍或绕行提示。只有相机朝向前方并满足[整幅近距条件](spatial.md#无地面时的近障提示)时，才可单独播报“障碍很近”，不提示转向，也不发出方向振动。朝地或朝天时没有这项例外。没有听到提示不表示前方畅通。

历史地面参考不能代替当前测量：原路线仍可在有效期内显示，但不能用来开始新的引导。整幅画面确认近障时，应用会撤下原路线。如果只是短时没有收到新测量帧，且没有新的障碍证据，应用可在刚测过且仍覆盖下一步的区域内沿用原路段，默认最多 2 s；不切换目标，也不因新相机画面而延长时限。

| 状态 | 触发条件 | 反馈与重复规则 |
|---|---|---|
| 失去测量 | 此前已有可靠引导，随后连续至少 1.5 s 无可用引导，且能根据可信位姿确认已经走出实测区域 | 异常振动并提示“暂时看不清”。同一次失测只提示一次，恢复可用引导后才可再次触发。刚启动、原地等待或仅有画面过期均不会触发；单独的近障提示不算引导恢复 |
| 前方受阻 | 当前有可用实测地面，前方存在已确认障碍且没有可用的绕行路线 | 路线提示“无法绕行”，需要转动手机寻找目标时提示“转动手机”。受阻持续 0.6 s 后触发异常振动，之后每 3 s 重复振动，不按此间隔重复播报 |

异常振动为三下短促振动，使用系统错误反馈，与方向引导振动不同。近障提示和失测告警独立判断。关闭“语音播报”或流式字幕占用语音时，两者都不插播语音；符合条件的振动不受影响。

> [!NOTE]
> 近障提示的实际效果，以及异常提示的语音听感与振动节奏，仍需真机确认；模拟和离线回放不能替代真机验收。

### 功能切换与恢复

打开设置或使用说明只暂停避障语音和振动，不停止已运行的测绘会话。临时失焦或进入后台时也保留运行意图，但系统可能中断采集；若启动尚未完成，应用可以取消启动并在回到前台后重试。恢复反馈后要有新的合格测量才开始引导，不补播旧提示，也不用暂停前的路线重新启动方向振动。

读文字会将相机交给文字识别；低视力模式使用普通相机，不做空间测绘。从这两种模式返回避障时，如果先前正在避障且未显式停止，应用会在前台重新测量。从空闲状态进入读文字不会自动开启避障。显式停止后需要再次开始，同样不能沿用上一次的测量。有关同一会话内的短时沿用条件，请参阅[结果有效期](spatial.md#结果有效期)。

## 拍照按键仲裁

拍照按键的硬件来源由设备能力与用户设置共同决定：

| 设备与设置条件 | 生效的拍照按键 |
|---|---|
| 支持相机控制按钮的设备 | 相机控制按钮（不显示屏幕拍照按钮） |
| 无相机控制按钮，且开启“音量键快捷操作” | 两个音量键（不显示屏幕拍照按钮） |
| 无相机控制按钮，且关闭“音量键快捷操作” | 屏幕拍照按钮 |

`AVCaptureEventInteraction` 会同时接管音量键和相机控制按钮，无法单独分离其中一种。启用后，相机运行期间音量键只触发拍照，不再调节系统音量。

### 画面描述与语音提问

按下拍照按键后，仲裁逻辑按以下顺序执行：

1. **短按描述**：按住不足 0.5 s 松手后，等待 0.35 s 连按窗口；确认无后续按下后取当前帧拍照并播放 880 Hz 提示音（连按两下按一次短按处理）。
2. **按住提问**：按住达到 0.5 s 时播放 440 Hz 提示音并开始录音识别；松手时立即停止录音、播放高音提示并提交图像与问题。若松手时麦克风尚未启动，本次提问取消，不再录音或提交。松手后语音识别最多额外等待 3 s 收尾，未识别到内容时不发送请求。首次提问需授予麦克风和语音识别权限。用户主动选择本机提问时强制使用本机语音识别，不可用则无法发起；联网提问的语音识别可能使用 Apple 服务。松手前进入设置或离开应用会取消这次提问，不提交照片或问题。

描述与提问期间暂停避障语音和振动，空间计算在后台继续运行。等待回答期间打开设置或失去焦点时，请求继续计算但取消朗读，恢复后不补播旧回答；显式取消或停止避障会直接终止当前请求。遇来电等系统音频中断时，未松手或未轻点“发送”的提问会取消，随后松手也不会发送。已经确认发送的请求可继续处理，但不再朗读本次回答。若系统未通知中断结束，应用会在返回前台或重新开始避障时检查音频是否可用，只恢复后续反馈。

### 流式字幕

流式字幕适用于机身相对固定的场景。启动后先用一句话概述所处地点与面前主要物体，随后仅播报画面中发生的动作，没有明显变化时保持安静。

1. **启动**：连按三下拍照按键（相邻间隔不超过 0.35 s），应用先播报“流式字幕已开启，再按一下退出”，随后播报开场句。
2. **退出**：运行中按一下拍照按键，播报“已退出流式字幕”。

流式字幕固定使用通义千问，不受默认服务商设置影响；未配置千问 API Key 时播报“流式字幕需要通义千问的 API Key”。运行期间暂停避障语音，符合条件的方向振动与异常状态振动仍可输出；进入设置或失焦时暂停朗读，返回后仅播报最新结果；停止避障或进入读文字时退出。请求参数请参阅[图像与文字识别](vision.md#流式字幕)。

### 读文字

三指按住屏幕 0.8 s 启动读文字。若避障正在运行，应用先播报“避障已暂停”，随后交出 ARKit 会话并启用后置主摄，待对焦和曝光稳定后自动拍照，并按物体类别前缀（例如“你面前的路标上写着：……”）逐句朗读。未检测到文字时播报“没有看到文字”，失败时播报“读文字失败，请重试”。

再次三指按住屏幕、运行“开始 PRTS”快捷指令或使用旁白双指双击均可退出读文字，随后恢复进入前的避障运行意图。

> [!NOTE]
> 启用旁白时多指手势由系统接管。聚焦主按钮后将转子调至“操作”，上下轻扫选择“读文字”并双击即可触发。

## 设置项

设置首页提供“智能”“交互”“语言和语音”与“使用说明”。Dev 构建可记录本地回放数据，并在最下方提供录制数据分享与清除操作；Release 构建不自动录制（见[开发指南](development.md#构建模式)）。API Key 保存在系统钥匙串，其余设置持久化在 `UserDefaults`：

| 导航路径 | 设置项 | 默认值 | 说明 |
|---|---|---|---|
| 智能 | 默认服务商 | 本机 | 可选本机、通义千问、DeepSeek 或自定义服务 |
| 智能 → 本机 | 增强模式 | 关闭 | 开启后语音提问改用联网版开放提示词，回答更发散，准确率可能下降 |
| 智能 → 通义千问 | 使用 Omni 模型 | 关闭 | 全部千问请求切至 `qwen3.8-omni-flash`，准确度提高但耗时增加 |
| 智能 → 通义千问 / DeepSeek | API Key、提问时深度思考 | 无 / 关闭 | 分服务商存储；深度思考仅用于语音提问，会显著增加等待时间 |
| 智能 → 自定义 | 服务地址、模型名称、API Key | 无 | 需支持 OpenAI Chat Completions 协议的视觉模型 |
| 智能 → 按功能设置 | 描述画面、语音提问、读文字 | 跟随默认服务商 | 支持按功能拆分服务商；读文字可选 Apple Vision，流式字幕固定千问 |
| 智能 → 全部服务 | 允许使用云端服务 | 关闭 | 发起操作时检查。关闭后不能新发起云端操作，本机功能不受影响；正在处理的请求和已开启的字幕会话不被打断 |
| 智能 | 高分辨率 | 关闭 | 提问与模型读文字的输入照片最长边由 1280 提至 1920 像素，耗时约增 0.5 s；描述保持 1280，字幕固定 960 |
| 交互 | 低视力模式 | 关闭 | 开启需确认；切至普通 RGB 相机，保留预览与智能功能，暂停深度检测和避障提示。相机运行时，首页状态显示“低视力模式”，而非“相机正在运行” |
| 交互 | 点按停止 | 关闭 | 取消主按钮长按 1 s 要求，适配辅助触控、眼动追踪或不便长按的用户 |
| 交互 | 音量键快捷操作 | 开启 | 仅在无相机控制按钮的设备显示 |
| 交互 | 三指快速朗读面前文字 | 开启 | 关闭后同时隐藏旁白“读文字”操作 |
| 交互 | 无画面模式 | 关闭 | 停止绘制相机视图以降低功耗与发热，分析、拍照和录音照常执行 |
| 交互 | 显示扫描网格 | 关闭 | 仅在 LiDAR 设备显示，在空间相机预览上绘制环境三维网格；低视力模式或无画面模式下不可用 |
| 语言和语音 | 语音播报、语速 | 开启 / 正常 | 关闭语音播报后不再自动播报相机状态和避障提示，主动触发的描述、提问和读文字仍正常朗读 |
| 语言和语音 | 跟随系统语言、播报语言 | 跟随系统 | 关闭跟随系统后可切换简体中文或 English（同时作用于应用界面和语音） |

方向引导依赖振动反馈，因此设置中不提供振动总开关。

## 应用内使用说明

首次冷启动时首页自动打开使用说明，之后可在设置最下方重新查看；通过快捷指令直接冷启动避障时不自动弹出，避免遮挡操作。说明窗口右下角按钮调用系统语音朗读全文。

说明文件按系统语言与机型硬件分为六份，位于 `PRTS/Features/Settings/UserGuide/`：

| 硬件支持情况 | 判定条件 | 对应文件 |
|---|---|---|
| 操作按钮 + 相机控制按钮 | `AVCaptureSession.supportsControls == true`（iPhone 16 / 17 系列、iPhone Air，不含 16e） | `camera-control.*.md` |
| 仅操作按钮 | `UserGuide.hasActionButton` 匹配机型标识符（iPhone 15 Pro / Pro Max、16e） | `action-button.*.md` |
| 两者均无 | iPhone 15 及更早机型、iPad | `basic.*.md` |

首次显示状态保存在 `userGuide.shown`；UI 测试可通过启动参数 `-userGuide.shown YES` 跳过引导弹窗。变更交互流程或设置结构时，需同步更新这六份文档。

## 无障碍支持

- **旁白（VoiceOver）**：开启旁白后由系统朗读界面焦点和设置变更，应用不再重复发声。避障和问答语音通过 `prefersAssistiveTechnologySettings` 匹配旁白语速与音色；错误信息以 `.callout` 展示并队列朗读；相机视图、渐变遮罩和装饰图标从旁白导航中隐藏。
- **动态字体**：字号达到 `AX1`–`AX5` 时，首页切换为可滚动单列布局，状态标签支持换行，设置入口支持长按打开大型内容查看器。
- **对比度与透明度**：开启系统“增强对比度”或“降低透明度”时，屏幕拍照按钮不透明度由 `0.25` 提高至 `0.85` 并增加深色底衬；iOS 26 及更高版本由系统适配液态玻璃效果。
- **无画面模式**：不创建 `CameraMetalView`，首页显示“无画面模式”状态卡（旁白朗读“无画面模式，相机仍在运行。”）。所有感知、拍照和 Dev 录制继续工作；旁白用户可配合系统三指三击屏幕幕帘进一步省电。

## 功能限制

- 精确避障依赖 LiDAR；`Release` 和 `Dev` 两种构建首页均采用 RGB 画面，不显示深度热图或路线，无 LiDAR 设备计算的单目相对深度可供内部诊断，反馈 `.unmapped`，不触发避障语音和方向振动（见[空间感知](spatial.md#无-lidar-模式)）。
- 尚不支持台阶、落差、目的地导航、公交或信号灯提醒。
- 应用仅支持竖屏，本地化界面目前覆盖简体中文和英文。
- 实体拍照按键已在 iPhone 17 Pro Max 验证；旁白全流程、Magic Tap、眼动追踪和 Siri 中文识别尚待视障用户实测（见[验证结果](validation.md)）。
