# 交互与设置规格

这份文档面向开发者和测试人员，记录 PRTS 的按键仲裁时序、功能互斥策略、语音振动状态机、无障碍适配以及设置项存储键。面向终端用户的简明指南放在 `PRTS/Features/Settings/UserGuide/`；模型请求和空间算法细节见[工程架构](architecture.md)与[图像与文字识别](vision.md)。

## 交互总览

| 功能 | 标准操作 | 无障碍与快捷操作 |
|---|---|---|
| 开始避障 | 轻点主按钮，或运行“开始 PRTS”快捷指令 | 旁白双指双击；Siri、轻点背面或操作按钮 |
| 停止避障 | 按住主按钮 1 s；开启“点按停止”后轻点 | 旁白双指双击，或主按钮的“停止”自定义操作 |
| 描述画面 | 短按拍照按键（松手早于 0.5 s） | 旁白双击屏幕拍照按钮 |
| 语音提问 | 按住拍照按键 0.5 s 后说话，松手发送 | 旁白“开始语音提问”/“结束语音提问并发送”；辅助触控或切换控制下点按两次 |
| 流式字幕 | 连按三下拍照按键，运行中按一下退出 | 使用屏幕拍照按钮或实体拍照键 |
| 读文字 | 三指按住屏幕 0.8 s | 旁白主按钮“读文字”操作，或运行快捷指令退出 |

操作按钮、轻点背面和 Siri 共用 `ToggleGuidanceIntent`（为兼容用户已保存的快捷指令保留原类型名）。触发时若正在读文字则退出读文字并恢复原相机状态，否则启动避障。

进入设置页、临时失焦或回到系统桌面时，应用保留相机和空间分析意图，只暂停语音与振动。真正切入后台后，iOS 会中断采集并挂起进程；回到前台时按当前状态恢复会话，不补播后台积压的旧结果。

## 避障状态提示

点击开始后，系统先播报“初始化中”，约 0.5 s 后（待占用网格初步建立）播报当前路线状态。从拍照描述、读文字或流式字幕恢复避障时，只等待 0.5 s，不再重复播报“初始化中”。

避障运行期间，以下两种异常持续状态使用连续三下短促振动提示（与方向引导振动区分）：

| 状态 | 触发条件 | 语音提示 | 重复间隔 |
|---|---|---|---|
| 无可用结果 | 跟踪受限、画面过期或分析暂停持续 1.5 s（刚启动尚未出结果时放宽至 4 s） | “暂时看不清” | 5 s |
| 前方受阻 | 前方存在已确认障碍且视野内无绕行路线，持续 0.6 s | 路线播报“无法绕行” | 3 s |

> [!NOTE]
> 以上两条异常提示的节奏与听感尚未在真机盲测中最终确认。

## 拍照按键与仲裁时序

拍照按键的具体硬件来源取决于机型与设置：

| 机型与设置条件 | 实际生效的拍照按键 |
|---|---|
| 支持相机控制按钮的机型 | 相机控制按钮（隐藏屏幕拍照按钮） |
| 不支持相机控制按钮，且开启“音量键快捷操作” | 两个音量键（隐藏屏幕拍照按钮） |
| 不支持相机控制按钮，且关闭“音量键快捷操作” | 屏幕拍照按钮 |

系统接口 `AVCaptureEventInteraction` 会同时接管音量键与相机控制按钮，无法单独分离。开启该功能后，相机运行期间音量键只触发拍照，不再调节系统音量。

### 描述画面与语音提问

按下拍照按键后的仲裁逻辑：

1. **短按描述**：松手早于 0.5 s 时，等待 0.35 s 连按窗口确认没有后续按压，再取当前帧拍照并播放 880 Hz 提示音（连按两下按一次短按处理）。
2. **按住提问**：按住达到 0.5 s 时播放 440 Hz 提示音并启动语音识别；松手后停止录音、播放高音提示并发送问题。松手后语音识别最多额外等待 3 s 收尾，未识别到文本时不发请求。首次提问会申请麦克风和语音识别权限。

描述和提问期间暂停避障语音和振动，空间计算在后台继续运行。等待回答期间若用户打开设置或切走焦点，推理任务继续完成但废弃播报，恢复后不补播旧回答；显式取消或停止避障会直接终止当前请求。遇到来电等系统音频中断时，立即释放麦克风并停止播报，已取到图像的推理仍可收尾。

### 流式字幕

流式字幕面向机身相对固定的场景，先用一句话概括地点和主要物体，随后只播报画面中的动作变化，静止时保持静默。

- **开关方式**：连按三下拍照按键（相邻间隔不超过 0.35 s）启动，先播报“流式字幕已开启，再次点按退出”，再播报开场句；运行中单按一下退出并播报“已退出流式字幕”。
- **服务依赖**：固定使用通义千问，不随默认服务商切换；未配置千问 API Key 时播报“流式字幕需要通义千问的 API Key”。
- **并发与中断**：运行期间只暂停避障语音，方向引导振动和异常状态振动继续工作；切入设置或失焦时暂停朗读，回到首页后仅播报最新结果；停止避障或触发读文字时退出字幕。请求参数见[图像与文字识别](vision.md#流式字幕)。

### 读文字

三指按住屏幕 0.8 s 启动读文字。如果避障正在运行，会先播报“避障已暂停”，随后交出 ARKit 相机并打开后置主摄，提示用户拿稳手机、等待对焦与曝光稳定后自动拍照，并按物体类别拼接前缀（如“你面前的路标上写着：……”）逐句朗读。无文字时播报“没有看到文字”，失败时播报“读文字失败，请重试”。

再次三指按住屏幕、运行“开始 PRTS”快捷指令或使用旁白双指双击均可退出读文字；结束后恢复进入前的避障运行意图。

> [!NOTE]
> 开启旁白时多指手势会被系统接管，可通过聚焦主按钮后将转子拨至“操作”，选择“读文字”双击触发。

## 设置项与存储

设置首页包含“智能”“交互”“语言和语音”和“使用说明”；Dev 构建末尾额外提供录制数据分享与清除入口（见[开发指南](development.md#构建模式)）。API Key 存入系统钥匙串，其余设置持久化在 `UserDefaults`：

| 页面路径 | 设置项 | 默认值 | 行为说明 |
|---|---|---|---|
| 智能 | 默认服务商 | 本机 | 可选本机、通义千问、DeepSeek 或自定义服务 |
| 智能 → 本机 | 增强模式 | 关闭 | 语音提问切换为联网版开放提示词，覆盖更多细节但可能降低本机模型准确度 |
| 智能 → 通义千问 | 使用 Omni 模型 | 关闭 | 全部千问调用改用 `qwen3.8-omni-flash`，准确度提升但响应变慢 |
| 智能 → 通义千问 / DeepSeek | API Key、提问时深度思考 | 无 / 关闭 | 分服务商保存；深度思考仅用于语音提问，会明显拉长等待时间 |
| 智能 → 自定义 | 服务地址、模型名称、API Key | 无 | 需支持 OpenAI Chat Completions 格式的视觉模型 |
| 智能 → 服务配比 | 描述画面、语音提问、读文字 | 跟随默认服务商 | 可按功能拆分服务商；读文字额外可选 Apple Vision，流式字幕固定千问 |
| 智能 → 全局 | 允许发送照片和提问 | 关闭 | 启用任何联网视觉服务前的总开关 |
| 智能 | 高分辨率 | 关闭 | 提问与读文字长边由 1280 提至 1920 像素，耗时约增加 0.5 s；描述保持 1280，字幕固定 960 |
| 交互 | 低视力模式 | 关闭 | 开启需二次确认；切至普通 RGB 相机，保留预览与问答，暂停深度和避障 |
| 交互 | 点按停止 | 关闭 | 取消长按 1 s 门槛，适配辅助触控、眼动追踪或手指不便长按的用户 |
| 交互 | 音量键快捷操作 | 开启 | 仅在无相机控制按钮的机型显示 |
| 交互 | 三指快速朗读面前文字 | 开启 | 关闭时同步隐藏旁白“读文字”自定义操作 |
| 交互 | 无画面模式 | 关闭 | 跳过 Metal 相机画面渲染以省电降温，空间分析与拍照正常运作 |
| 交互 | 显示扫描网格 | 关闭 | 仅在 LiDAR 机型显示，叠加环境三维网格（不渲染路线） |
| 语言和语音 | 语音播报、语速 | 开启 / 正常 | 关闭语音播报只影响避障提示，主动触发的描述和问答仍正常朗读 |
| 语言和语音 | 跟随系统语言、播报语言 | 跟随系统 | 关闭跟随系统后可手动指定中文或 English |

振动没有关闭开关，因为左右偏航引导强依赖触觉节奏。

## 应用内使用说明

首次冷启动时首页自动弹出使用说明，之后可在设置末尾随时打开；通过快捷指令直接冷启动避障时不自动弹出，以免遮挡出发操作。窗口右下角提供全文语音朗读按钮。

文案根据系统语言与设备硬件分为六份，存放在 `PRTS/Features/Settings/UserGuide/`：

| 硬件组合 | 判定依据 | 对应文件 |
|---|---|---|
| 操作按钮 + 相机控制按钮 | `AVCaptureSession.supportsControls == true`（iPhone 16 / 17 系列、iPhone Air，不含 16e） | `camera-control.*.md` |
| 仅操作按钮 | `UserGuide.hasActionButton` 匹配机型标识符（iPhone 15 Pro / Pro Max、16e） | `action-button.*.md` |
| 两者均无 | iPhone 15 及更早机型、iPad | `basic.*.md` |

首次弹出记录在 `userGuide.shown`；UI 测试通过启动参数 `-userGuide.shown YES` 跳过引导弹窗。调整操作逻辑或设置项时，需同步更新这六份 Markdown 文档。

## 无障碍适配

- **旁白（VoiceOver）**：开启时由系统负责播报界面焦点和设置变更，应用内部不再重复发声。避障与问答语音遵循系统 `prefersAssistiveTechnologySettings` 语速与音色；错误提示以 `.callout` 展示并队列朗读；相机视图、渐变遮罩和装饰图标从旁白树中隐藏。
- **动态字体**：字号达到 `AX1`–`AX5` 时，首页自动转为可滚动单列布局，状态标签允许折行，设置图标支持长按弹出大型内容查看器。
- **对比度与透明度**：开启系统“增强对比度”或“降低透明度”时，屏幕拍照按钮透明度从 `0.25` 提升至 `0.85` 并叠加深色底衬；iOS 26 及以上系统同步应用液态玻璃效果适配。
- **无画面模式**：不实例化 `CameraMetalView`，首页展示“无画面模式”状态卡（旁白朗读“无画面模式，避障照常运行。”）。所有感知、拍照与 Dev 录制照常运行；旁白用户可配合系统三指三击屏幕幕帘进一步省电。

## 现阶段功能限制

- 精确避障依赖 LiDAR；无 LiDAR 机型仅提供单目估算深度与路线示意（见[空间感知](spatial.md#无-lidar-模式)）。
- 尚无台阶、落差、目的地导航、公交与红绿灯识别能力。
- 界面仅支持竖屏，内置本地化目前覆盖简体中文和英文。
- 实体拍照按键已在 iPhone 17 Pro Max 实机验证，旁白全流程、Magic Tap、眼动追踪和 Siri 中文唤醒仍需更多视障用户实测（见[验证结果](validation.md)）。
