# 功能与操作

本文介绍 PRTS 的各项功能、操作方式、设置项和无障碍支持。各功能的实现细节请参阅[工程架构](architecture.md)和[图像与文字识别](vision.md)。

## 操作方式

| 功能 | 标准操作 | 替代操作 |
|---|---|---|
| 开始避障 | 按操作按钮（“开始 PRTS”快捷指令），或轻点主按钮 | 旁白双指双击；Siri 或轻点背面 |
| 停止避障 | 按住主按钮 1 s；开启“点按停止”后点按即可 | 旁白双指双击，或主按钮的“停止”操作 |
| 描述画面 | 短按拍照按键（不足 0.5 s） | 旁白双击屏幕拍照按钮 |
| 语音提问 | 按住拍照按键说话，松开后发送 | 旁白“开始语音提问”和“结束语音提问并发送”操作；辅助触控或切换控制下点按两次 |
| 朗读文字 | 三指按住屏幕 0.8 s | 主按钮的旁白“读文字”操作 |

如需使用操作按钮，请在 iPhone 的“设置 → 操作按钮”中选择“快捷指令”，再选择“开始 PRTS”。该快捷指令启动避障，读文字时退出读文字；它也可以分配给轻点背面，或通过 Siri 运行。为兼容已保存的快捷指令，其类型名仍为 `ToggleGuidanceIntent`。

进入设置时相机继续运行，避障反馈暂停。切到后台时暂停采集，返回前台后恢复已开始的避障。

### 拍照按键

拍照按键根据设备和设置确定：

| 设备或设置 | 拍照按键 |
|---|---|
| 有相机控制按钮 | 相机控制按钮，不显示屏幕拍照按钮 |
| 无相机控制按钮，开启“音量键快捷操作” | 两个音量键，不显示屏幕拍照按钮 |
| 无相机控制按钮，关闭“音量键快捷操作” | 屏幕拍照按钮 |

`AVCaptureEventInteraction` 同时接管音量键和相机控制按钮，无法单独接管其中一种。开启后，音量键在相机运行期间用于拍照，不再调节音量。

### 描述画面与语音提问

短按拍照按键时，松开即拍照，并播放 880 Hz 提示音。按住达到 0.5 s 时播放 440 Hz 提示音并开始录音；松开后停止录音，播放高音提示，并将问题与照片一起发送。语音识别最多额外等待 3 s，未识别到内容时不发送请求。首次提问需要授予麦克风和语音识别权限。

描述和回答期间，避障的语音和振动暂停，空间分析继续运行；朗读结束后恢复。取消操作、进入后台、打开设置、停止避障或来电都会使当前请求失效，较晚返回的回答不会被朗读。

### 朗读文字

如需朗读面前的文字，请三指按住屏幕 0.8 s。应用会提示用户拿稳手机，等待对焦和曝光稳定后自动拍照，并以“你面前的路标上写着：……”的形式逐句朗读。未识别到文字时，应用提示“没有看到文字”。

如果避障正在运行，应用会先播报“避障已暂停”。如需退出，请再次三指按住屏幕、运行“开始 PRTS”快捷指令或使用旁白双指双击；打开设置、进入后台和来电时也会自动退出。退出后恢复读文字之前的避障状态。

> [!NOTE]
> 旁白开启时，多指手势由旁白接管。请先聚焦主按钮，再将转子切换到“操作”，上下轻扫选择“读文字”，然后双击。

## 设置

| 位置 | 设置项 | 默认值 | 说明 |
|---|---|---|---|
| 设置首页 | 点按停止 | 关闭 | 无需长按主按钮即可停止；辅助触控、眼动追踪或不便长按时可开启 |
| 设置首页 | 非盲模式 | 关闭 | 开启前确认；保留相机、描述、提问和文字朗读，关闭避障语音与振动 |
| 智能设置 | 服务 | 本机（离线） | 可选通义千问、DeepSeek 或自定义服务。选择联网服务时需要配置 API Key 并允许上传照片 |
| 智能设置 | 增强模式 | 关闭 | 仅在选择本机服务时显示。开启后本机语音提问使用联网服务的提问提示词，回答范围更广，准确性可能下降 |
| 智能设置 | 提问时深度思考 | 关闭 | 仅在选择千问或 DeepSeek 时显示，只影响语音提问，会增加等待时间 |
| 智能设置 → 拍照按键 | 音量键快捷操作 | 开启 | 仅在无相机控制按钮的设备上显示 |
| 智能设置 → 读文字 | 三指快速朗读面前文字 | 开启 | 关闭后同时隐藏旁白“读文字”操作 |
| 智能设置 → 读文字 | 识别服务 | 智能识别 | 跟随智能设置中的服务商，远端不可用时使用本机模型；也可选择 Apple Vision |
| 语音 | 语音播报、语速 | 开启、正常 | 用户主动请求的描述和回答不受“语音播报”开关影响 |
| 语言 | 跟随系统语言、播报语言 | 跟随系统 | 关闭“跟随系统语言”后才显示“播报语言”，可选中文或 English |
| 显示 | 无画面模式 | 关闭 | 停止绘制相机画面，避障分析和反馈照常运行 |
| 显示 | 扫描网格 | 关闭 | 仅在 LiDAR 设备上显示；绘制环境网格和规划路线 |

振动始终开启，没有关闭选项，因为方向提示依赖振动。设置页的各项开关附有旁白提示；旁白开启时，应用不再重复播报设置变化，由旁白朗读控件状态。

API Key 存储在钥匙串中，其他设置存储在 UserDefaults 中。开发版的附加设置请参阅[开发指南](development.md#开发版与标准版)。

## 使用说明

首次打开应用时，首页会自动弹出使用说明，之后可以在设置页的最后一项“使用说明”中重新打开。通过操作按钮冷启动时不弹出，以免挡住避障。说明窗口右下角的按钮使用系统语音朗读全文。说明的语言跟随 iPhone 系统语言，内容按机型分为三类：

| 类别 | 机型 | 文件 |
|---|---|---|
| 操作按钮和相机控制按钮 | iPhone 16 / 17 系列、iPhone Air（iPhone 16e 除外） | `camera-control.*.md` |
| 仅操作按钮 | iPhone 15 Pro、iPhone 15 Pro Max、iPhone 16e | `action-button.*.md` |
| 两者都没有 | iPhone 15 及更早机型 | `basic.*.md` |

说明文件位于 `PRTS/Features/Settings/UserGuide/`，中文和英文各一份。相机控制按钮通过 `AVCaptureSession.supportsControls` 判断；操作按钮没有系统接口，按机型标识符判断（`UserGuide.hasActionButton`）。是否已自动弹出记录在 `userGuide.shown` 中；UI 测试通过启动参数 `-userGuide.shown YES` 跳过自动弹出。修改界面或操作方式时，请同步更新这六个文件。

## 无障碍支持

### 旁白

旁白开启时，相机状态和设置变化由旁白朗读，应用不重复播报。避障提示和拍照回答由应用输出，并通过 `prefersAssistiveTechnologySettings` 使用旁白的音色和语速。错误信息以 `.callout` 字号显示，并额外朗读一次。相机画面、渐变和装饰图标不参与旁白导航。

### 动态字体

字号达到 AX1–AX5 时，主页切换为可滚动的单列布局，状态面板允许换行，开发指标自动隐藏。设置入口保留齿轮图标，长按可打开大型内容查看器。

### 对比度与透明度

开启“增强对比度”或“降低透明度”时，屏幕拍照按钮的不透明度从 0.25 提高到 0.85，并增加深色背景。在 iOS 26 及更高版本中，液态玻璃效果由系统适配。

### 无画面模式

无画面模式不创建 `CameraMetalView`，主页显示“无画面模式 · 避障照常运行”。分析、拍照和诊断记录继续运行；避障语音与振动仍受非盲模式控制。如需进一步省电，旁白用户可以三指三击开启系统的屏幕幕帘。

> [!NOTE]
> 开发版的“隐藏相机画面”仅将底图替换为黑色，叠加层仍以 30 FPS 绘制，与无画面模式不同。

## 限制

- 避障需要 LiDAR。无 LiDAR 设备只能显示估算深度和路线示意，不提供可靠的障碍距离，详见[空间感知](spatial.md#无-lidar-模式)。
- 尚不支持台阶和落差检测、目的地导航、公交或信号灯提醒。
- 设置界面、拍照设置和拍照按钮提供中文和英文，开发者选项仅提供中文。
- 应用仅支持竖屏。
- 开发版图例主要依靠颜色区分地面和障碍。
- 实体拍照按键已在 iPhone 17 Pro Max 上验证。旁白、Magic Tap、辅助触控、眼动追踪和 Siri 中文识别尚未经过视障用户实测，详见[验证结果](validation.md)。
